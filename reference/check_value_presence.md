# Check for value presence

If value is not present in vector it takes its first value.

## Usage

``` r
check_value_presence(val, vect, warn_msg = "")
```

## Arguments

- val:

  element of vector `vect`

- vect:

  vector of values

- warn_msg:

  warning message to be displayed if `val` not in `vect`

## Value

updated val
